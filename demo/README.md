# 運用コンソール（社内デモ）

商談で「実際にどう動いているか」を見せるための画面です。
**SaaSとして提供するものではありません。** 公開サイトには含めていません。

## 使い方

`demo/console/index.html` をブラウザで開くだけです。サーバは不要です。

左の柱で7つの工程を切り替えます。画面の水色が機械の工程、金色が人の工程です。

## 中身は実データです

| 表示 | 出どころ |
|:--|:--|
| 記事数・平均スコア・平均文字数 | `articles/*.md` の実測 |
| 食い合い審査の出力 | `scripts/kw_guard.py` の実行結果をそのまま |
| 機械採点の出力 | `scripts/score_check.py` の実行結果をそのまま |
| 人が判断する81項目 | 構成審査14＋AI感排除7＋6観点60 |

作り話の数字は入れていません。

## 数字を最新にする

記事が増えたら `demo/console/data.json` を作り直し、`index.html` の
`<script id="D">` の中身に貼り替えます（生成手順はコミット履歴を参照）。
