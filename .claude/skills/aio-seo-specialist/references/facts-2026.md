# 確かめた事実と出典（2026年9月時点）

## Google の公式見解
出典: Google 検索セントラル「AI最適化ガイド」 https://developers.google.com/search/docs/fundamentals/ai-optimization-guide

| 通説 | 公式の見解 |
|:--|:--|
| llms.txt がAI検索に効く | 無視する。害も益も無い |
| 構造化データがAI引用に必須 | 必須ではない。AI検索向けの専用スキーマも存在しない |
| 内容を細かく刻むと理解されやすい | 不要。複数の話題があるページも理解できる |
| AI向けの書き方がある | 不要。同義語も文意も理解する |
| GEO/AEOの技法 | Googleの仕組みに照らして効かない |

効くと明記: 独自の視点（一次体験）／非コモディティの内容／クロールできること。

スパムポリシー「大量生成されたコンテンツの不正使用（Scaled content abuse）」: https://developers.google.com/search/docs/essentials/spam-policies
（このプロジェクトは月60本の上限と、量産の兆候で本数を自動で落とす pace.py を持つ）

## Ahrefs の実測（75,000ブランド・Spearman相関）

| 要因 | AI Overviews | ChatGPT |
|:--|--:|--:|
| YouTubeでの言及 | 0.712 | 0.737 |
| リンクの無いWeb言及 | 0.656 | 0.664 |
| ブランド名のアンカー | 0.527 | 0.511 |
| 指名検索の量 | 0.392 | 0.352 |
| Domain Rating | 0.326 | 0.266 |
| 被リンク本数 | 0.218 | 上位に入らない |

AI回答がブランドに触れてもリンクするのは28%。Web言及の下位50%はAI検索でほぼ不可視。
著者自身が「相関≠因果」と明記。対象は DR>40 のドメイン。

## 自社データでの検証（validate_rules.py）
| 判断 | 実測 |
|:--|:--|
| 品質スコア | 逆（91〜93点が96点以上より4.1位上） |
| 内部リンクの本数 | 成果を分けていない |
| 記事の長さ | 成果を分けていない（5,500字未満が最良の17.6位） |
| 質問形の見出し | 1〜3割の記事が17.3位、ゼロが21.5位（本数不足で参考値） |
| 検索語の性質 | 成果を分けている（同じ6〜10位でCTR 1.04% と 2.80%） |

下限5,000字の決まりが375本中299本を5,500〜6,500字に寄せ、量産の指紋になっていた → depth（quick/standard/deep）で長さを変える。
