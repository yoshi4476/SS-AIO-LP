# CLAUDE.md 0.3 の原文（2026-10-03 にスキルへ移設したときの控え）

## 0.3 2026年9月時点で確かめた事実（通説を採らない）

**一次情報で確認できたものだけを載せる。** SEO業界の記事が広めている主張の多くは裏付けが取れなかった。

### Googleが公式に否定していること（[AI最適化ガイド](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide)）

| 通説 | 公式の見解 |
|:--|:--|
| llms.txt がAI検索に効く | **無視する。** 害も益も無い |
| 構造化データがAI引用に必須 | **必須ではない。** AI検索向けの専用スキーマも存在しない |
| 内容を細かく刻むと理解されやすい | 不要。複数の話題があるページも理解できる |
| AI向けの書き方がある | 不要。同義語も文意も理解する |
| GEO/AEOの技法 | 「Googleの仕組みに照らして効かない」 |

**効くと明記されているのは3つだけ**: 独自の視点（一次体験）／一般論に留まらない非コモディティの内容／クロールできること。
リッチリザルト目的の構造化データは引き続き有効なので、いまの出力は変えない。

### 実測で分かった要因の順番（Ahrefs・75,000ブランド・Spearman相関）

| 要因 | AI Overviews | ChatGPT |
|:--|--:|--:|
| YouTubeでの言及 | 0.712 | 0.737 |
| **リンクの無いWeb言及** | 0.656 | 0.664 |
| ブランド名のアンカー | 0.527 | 0.511 |
| 指名検索の量 | 0.392 | 0.352 |
| Domain Rating | 0.326 | 0.266 |
| **被リンク本数** | 0.218 | 上位に入らない |

**被リンクより「言及」が3倍効く。** AI回答がブランドに触れてもリンクするのは28%だけなので、
リンクの有無で数えると実態を取り逃がす。Web言及の下位50%はAI検索でほぼ不可視。
ただし著者自身が「相関≠因果」と明記し、対象はDR>40のドメインに限られる。**当社は条件を満たさない可能性がある。**

### 学術的な実測（[arXiv 2605.14021](https://arxiv.org/abs/2605.14021)・55,393クエリ・2026-03〜04）

- AI Overviewの表示率 **13.7%**。ただし**質問形のクエリでは64.7%**
- AIO引用ドメインの**約30%は1ページ目に出ていない** → 順位とは別の選択機構がある
- 引用された主張の11.0%は引用元に裏付けが無い（脱落が主因）

### 自社データで確かめた結果（`validate_rules.py`）

| 判断 | 実測 |
|:--|:--|
| 品質スコア | **逆になっている**（91〜93点が96点以上より4.1位上） |
| 内部リンクの本数 | **成果を分けていない**（順序が入れ替わる） |
| 記事の長さ | **成果を分けていない**（5,500字未満が最良の17.6位） |
| 質問形の見出し | 1〜3割の記事が17.3位、ゼロが21.5位（**4.2位差。ただし本数不足**） |
| 検索語の性質 | 成果を分けている |

**下限5,000字の決まりが、375本中299本を5,500〜6,500字に寄せていた。**
「全記事が同じ長さに揃うと量産の指紋になる」と自分で書きながら、その状態を作っていた。
長さの基準を変える前に、`depth: quick` を実際に使って比べる。
