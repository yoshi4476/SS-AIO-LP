# 独自調査レポート企画（G-ran 通算3,200店舗以上データ）

> 目的: 「引用したくなる一次データ」の提供者になる。被リンク獲得力が最も高い施策。
> 1つの調査を **調査レポートページ + プレスリリース + 業界メディア寄稿** の3つに展開する。
> 数字は実データからのみ算出する。推測値・概算での公表は行わない。

## なぜこれが最も効くのか

被リンクは「作る」ものではなく「集まる」ものです。第三者が自発的にリンクする理由は
ほぼ1つで、**他では手に入らない数字を引用したいから**です。

御社は通算3,200店舗以上のMEO運用データを持っています。この規模の実運用データを
公開できる会社は国内にほとんどなく、以下の相手が引用元として必要とします。

| 引用する側 | 引用する理由 |
|---|---|
| Webマーケ系メディア・ブログ | 記事の根拠として一次データが要る。出典リンクは慣習として必ず付く |
| 記者・ライター | 「◯◯という調査によると」の◯◯になる |
| 競合を含む同業他社 | 自社に無いデータは引用するしかない |
| ChatGPT・Perplexity等 | 数値付き断定文かつ出典が明確な情報を優先的に引用する |

## 必要なデータ（この形式でご提供ください）

Googleビジネスプロフィールの管理画面、または G-ran の管理データから、
**1店舗1行**のCSV / スプレッドシートで書き出してください。店舗名・住所は不要です。

| 列 | 内容 | 必須 | 備考 |
|---|---|:--:|---|
| 業種 | 飲食店 / 美容室 / クリニック 等 | ◎ | 分析の軸になる最重要列 |
| 都道府県 | 大阪府 等 | ○ | 地域差の分析に使う |
| 運用開始月 | 2025-04 等 | ◎ | 運用期間の効果を見る |
| 集計月 | 2026-06 等 | ◎ | 月次で並んでいる形が理想 |
| マップ表示回数 | 月間 | ◎ | 主要指標 |
| 検索表示回数 | 月間 | ○ | |
| 経路検索数 | 月間 | ◎ | 来店行動の代理指標 |
| 電話タップ数 | 月間 | ◎ | 同上 |
| サイトクリック数 | 月間 | ○ | |
| 口コミ総数 | 累計 | ◎ | |
| 平均評価 | 4.2 等 | ◎ | |
| 口コミ返信率 | 0〜100% | ◎ | **最も価値が高い列** |
| 投稿回数 | 月間 | ○ | |
| 写真投稿枚数 | 月間 | ○ | |

**最低限これだけでも成立します**: 業種 / 集計月 / マップ表示回数 / 経路検索数 / 口コミ返信率 / 平均評価

期間は直近12ヶ月あると「推移」が語れて価値が上がります。1時点だけでも分析は可能です。

## 出せる分析の候補（データが揃った時点で確定）

| # | 分析テーマ | なぜ引用されるか |
|---|---|---|
| 1 | 口コミ返信率と経路検索数の関係 | 「返信すると本当に来店が増えるのか」は全店舗経営者の関心事。憶測で語られがちで実データがない |
| 2 | 業種別・マップ表示回数の中央値 | 「うちの数字は多いのか少ないのか」の基準がどこにもない。ベンチマークは引用され続ける |
| 3 | 平均評価の帯と行動率 | 星4.0と4.5で来店行動がどれだけ違うか |
| 4 | 運用期間別の伸び方 | 「MEOは何ヶ月で効果が出るか」への実データ回答 |
| 5 | 投稿頻度と表示回数の相関 | 施策の費用対効果の根拠 |

## 匿名化と公表のルール（厳守）

クライアントのデータを扱うため、以下を機械的に強制します。

- 店舗名・住所・電話番号・GBP IDは**取り込み時点で破棄**する（集計スクリプトに渡さない）
- 公表するのは**集計値のみ**。個別店舗の数値は一切載せない
- **1セグメントあたり30店舗未満の区分は公表しない**（少数だと特定につながるため）
- 都道府県より細かい地域区分は使わない
- グラフ画像に「出典: セブンセンシズ株式会社（AI集客ラボ）」を焼き込む（転載時に言及が残る）

> **確認が必要な点**: クライアントとの契約に、匿名化・集計後のデータを対外公表できる条項が
> あるかをご確認ください。無い場合は、公表前に同意取得か、契約書への追記が必要です。
> ここは法務判断が要る箇所のため、実データを受け取る前に必ずご確認ください。

## 3展開の設計（1つの調査を3回使う）

| 展開先 | 形 | 狙い |
|---|---|---|
| 調査レポートページ | ai.7senses.co.jp に専用ページ。グラフ+表+方法論を明記 | リンク先になる本体。出典として指定される |
| プレスリリース | 調査結果のうち最も意外な1点を見出しに | 転載メディアからの被リンクを一度に獲得 |
| 業界メディア寄稿 | 同じデータを実務の文脈で解説 | 権威ドメインでの著者名言及（E-E-A-T） |

## 私が行う作業（データ受領後）

1. 匿名化・クレンジング（個人情報列の破棄、外れ値処理、n数チェック）
2. 集計スクリプトの作成（再現可能な形で残す。翌年の第2回調査でそのまま使える）
3. グラフ生成（出典クレジット焼き込み済み）
4. 調査レポートページの作成（方法論・n数・調査期間を明記。ここを書かないと引用されない）
5. プレスリリース原稿の仕上げ
6. 寄稿ピッチ文の作成

## 実データが揃うまでにできること

データ提供が難しい場合の代替案として、**自社3サイトの実測データによる調査**も可能です。
GSCとGA4から「AI検索経由の流入がどう推移したか」を実測できます。
ただし現時点では公開1ヶ月・記事30本規模のため、データの厚みは G-ran データに遠く及びません。
本命は G-ran データです。
