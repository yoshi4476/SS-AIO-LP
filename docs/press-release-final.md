## 記者に聞かれたときの備え

| 聞かれること | 答え方 |
| --- | --- |
| 3,200店舗の根拠は？ | 自社のMEO運用サービス「G-ran」の累計運用店舗数（自社集計・2026年7月時点）。**社数ではなく店舗数** |
| メディアの成果は？ | 開設から日が浅く、順位・流入の実績を出せる段階ではない。**数字を作って答えない** |
| 記事は誰が書いているか | 代表監修のもと編集体制で制作。AIも制作工程で使っているが、事実確認と一次情報の追加は人が行う |
| 無料診断は本当に無料か | 登録不要・無料。営業目的の個人情報取得は行っていない |

**成果を聞かれたときに数字を作らないこと。** 立ち上げ期であることを正直に答えるほうが、
後で数字が合わなくなるより安全です。
