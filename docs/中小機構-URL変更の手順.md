# 中小機構の支援事業者ページ URL変更（最優先）

> **いま存在する唯一の外部リンクが、旧サイトに向いています。** 行き先を変えるだけで、
> 公的機関（.go.jp）からの1本が本命サイトへ向きます。無料・申請1回・審査なし。

## なぜこれが最優先か

| 事実 | 出どころ |
|:--|:--|
| 3サイトとも第三者から確認できた被リンクは**0本** | `data/backlinks.json`（2026-09-15確認） |
| 中小機構の支援事業者ページは、いま `www.7senses.co.jp`（別業者が管理する旧サイト）を向いている | 同上 |
| 旧サイトから3サイトへのリンクは**0本**。評価がそこで止まっている | 実測（2026-09-22） |

**記事を何本書いても、この1本は動きません。** 外部リンクは相手のある話で、機械では埋められません。

なお、AI検索での可視性は被リンク（相関0.218）よりリンクの無い言及（0.656）のほうが強く相関します。
それでも**これを先にやる理由は、すでに存在するものを付け替えるだけで済むから**です。新規獲得より確実に速く終わります。

## 変更する内容

| 項目 | 現在 | 変更後 |
|:--|:--|:--|
| 掲載URL | https://www.7senses.co.jp/ | **https://lp.7senses.co.jp/** |

**lp.7senses.co.jp（AI導入補助金サポート）を指定します。** 支援事業者の一覧から来る人は
補助金の情報を探しているため、コーポレートサイトより適しています。検索エンジンにとっても、
リンク元のページの主題と行き先の主題が一致するほうが評価が通りやすくなります。

## 手順

1. **事業者ポータルにログイン**（gBizIDプライムが必要）
   - デジタル化・AI導入補助金の支援事業者向けポータル
2. **登録情報の編集画面を開く**
3. **「ホームページURL」または「自社サイトURL」を書き換える**
   - `https://lp.7senses.co.jp/`（末尾のスラッシュあり）
4. **保存・申請**（内容変更のため審査は通常不要）
5. **反映を確認**（数日〜2週間）

### 編集画面が見つからない場合

事務局に電話します。

```
デジタル化・AI導入補助金 事務局
  0570-666-376（IP電話からは 050-3133-3272）
```

伝える内容です。

> セブンセンシズ株式会社、法人番号 3120001227825 です。
> デジタル化・AI導入補助金の登録支援事業者として掲載いただいている
> ホームページURLを変更したいのですが、事業者ポータルのどこから編集できますか。

## 変更後に確かめること

```bash
python scripts/mentions.py --check     # 掲載が生きているか
python scripts/backlinks.py            # 被リンクの登録（あれば）
```

掲載ページはこちらのアクセスを403で弾くため、**機械では「確かめられない」としか出ません。**
ブラウザで目視確認し、変わっていたら登録します。

```bash
python scripts/mentions.py --add "<掲載ページのURL>" --where "中小機構 支援事業者検索" --linked
```

## 効果の測り方

この1本が入る前と後で、`lp.7senses.co.jp` の表示回数と順位を比べます。

```bash
python scripts/key_queries.py --track    # 主要クエリの順位（週次で記録済み）
python scripts/brand_search.py           # 指名検索の推移
```

**被リンクが0本の状態から1本入るので、効果があれば見えます。** いま0本なので、
「被リンクは効くのか」を自社のデータで初めて確かめられる機会でもあります。
