# 記事の音声・動画化プラン（LLMO: 言及ソースの多面化）

> サイト内には「🎧 聴く」ボタン（Web Speech API・実装済み）があり、追加費用ゼロで全記事が音声で聴けます。
> 本ドキュメントは、その先の「YouTube展開」の手順書です（実施はユーザー判断・公開後）。

## なぜ動画化がLLMOに効くか

ChatGPT系は「複数の独立ソースでの言及」を重視します。YouTubeは (1)Google検索結果に動画枠で再露出できる
(2)概要欄から記事へ被リンクを張れる (3)チャンネル自体がエンティティ情報源になる、の三重で効きます。

## 最小工数の制作フロー（1本30分目安）

1. **台本**: 記事の「H2直下の1文結論」を並べるだけで台本になる（AIO構造の副産物）
2. **スライド**: `scripts/make_diagram.py` の図解+アイキャッチを流用（新規デザイン不要）
3. **音声**: VOICEVOX（無料・商用可）等で読み上げ生成、または本人ナレーション
4. **結合**: ffmpeg でスライド+音声を結合（`winget install Gyan.FFmpeg`）
   ```
   ffmpeg -loop 1 -i slide.png -i voice.wav -c:v libx264 -tune stillimage -shortest out.mp4
   ```
5. **投稿**: タイトルは記事と同一KW / 概要欄の1行目に記事URL / 固定コメントにも記事リンク

## チャンネル設計

- チャンネル名: AI集客ラボ【セブンセンシズ】（サイトと表記統一 = エンティティ同定）
- 概要欄: llms.txtの運営者情報と同じ文面+全リンク（サイト/LP/補助金/コーポレート）
- 週1本・記事と同時公開が理想。まず既存7記事の動画化から
