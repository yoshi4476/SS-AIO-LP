## 10. トラブルシューティング

### API 503エラー
1. 即フォールバックしない → 10分間隔ポーリング（最大6回=60分）
2. 6回連続503: エラーログ記録 → 該当Phaseスキップ（一次情報収集のみ） or 翌日再実行

### 画像生成失敗
画像はローカル生成のため、APIの失敗による欠落は起きない。
1. フォントが見つからない → YuGothB / meiryob の有無を確認
2. 文字がはみ出す → 自動縮小が効かない長さ。タイトルか項目名を短くする
3. 生成漏れ → build.py が機械検出する。`make_images.py <slug>` を再実行

### ビルド・デプロイエラー（静的サイト）
1. build.py エラー → Markdown構文（テーブル・コードブロックの閉じ忘れ）を確認
2. HTML崩れ → テンプレート変数の未置換・見出し階層のネスト崩れを確認
3. Cloudflare Pages デプロイ失敗 → ダッシュボードのビルドログ確認。出力ディレクトリが `site/` か確認
4. 画像リンク切れ → `site/images/{slug}/` への配置漏れ・パスの大文字小文字を確認
5. Schema構文エラー → JSON-LDのエスケープ漏れ（本文引用符）を確認

### スプレッドシートトークン期限切れ
OAuthトークンは通常7日で期限切れ → リフレッシュトークンで再取得 / MCP再認証 / sheets-token.json の更新日確認

### Ahrefs API units枯渇
1. 月次リセット日確認。リセットまでAhrefsクエリ使用禁止
2. KW選定は記事作成ログの未着手行から取得
3. リセット後の優先順位: site-explorer-metrics → organic-keywords → top-pages → rank-tracker-overview

### インデックス登録が進まない
1. site/sitemap.xml のURL数確認
2. build.py のsitemap生成ロジック確認（新記事の追記漏れ）
3. Indexing APIサービスアカウントのGSCオーナー権限確認
4. robots.txt ブロック確認
5. 手動: GSC URL検査ツールで1記事ずつ登録

### AI検索に引用されない場合

前提: AI Overview引用の最大の前提はGoogle検索上位表示。まず順位を確認。

1. **順位10位以内か確認** — 圏外・2ページ目以降なら通常SEOリライト（8.2最高優先度）を先に
2. **robots.txt / クローラーアクセス確認** — GPTBot/OAI-SearchBot/ClaudeBot/PerplexityBot のブロック、WAF/CDN（Cloudflare等）の自動ブロック（アクセスログで403/429確認）
3. **抽出可能構造確認** — 冒頭200字断言回答 / H2直下1文結論 / FAQ・比較テーブル・定義ブロック
4. **情報鮮度確認** — dateModified 6ヶ月以上前なら鮮度更新。「◯年◯月時点」表記追記
5. **Schema確認** — リッチリザルトテストでFAQPage/Article/BreadcrumbListエラーなし、本文との一致
6. **独自性確認** — 「まとめ直し記事」になっていないか。独自数値ファクト・一次情報追加
7. **全て満たしても引用されない** — 競合引用元ページと構造差分分析、ドメイン権威性（被リンク・メディア露出・指名検索）の中長期強化

### GSC生成AIパフォーマンスレポートにデータが出ない

1. レポート導入は2026年6月。プロパティにより反映に時間差あり
2. データなし=引用されていない可能性大 → 上記「AI検索に引用されない場合」を実施
3. インプレッションのみでクリック・クエリ内訳が見えないのは仕様 → GA4 AI参照元とMonthly AI Citation Checkで補完
