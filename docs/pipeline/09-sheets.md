## 9. スプレッドシート構成（詳細）

### KW戦略タブ
A:KW / B:Volume / C:KD / D:Intent（info/commercial/transactional） / E:CV距離（Do>Buy>Commercial>Info） / F:自社独自価値 / G:AI Overview表示（表示あり/なし/不明） / H:Status / I:備考

### トピッククラスタータブ
A:KW / B:Volume / C:KD / D:カテゴリ / E:クラスター名 / F:種別（ピラー/クラスター） / G:優先度（A/B/C） / H:Status / I:URL

### X一次情報タブ
A:記事# / B:KW / C:投稿者名 / D:投稿日 / E:投稿URL / F:本文（note_tweet全文・200字以上） / G:imp / H:RT / I:Like / J:メディアURL / K:記事への活用方法
※記事間に空行を入れない。

### YouTube一次情報タブ
A:記事# / B:KW / C:動画タイトル / D:チャンネル名 / E:動画URL / F:再生数 / G:文字起こしパス / H:文字起こし完了（○/×） / I:要約 / J:記事への活用方法
※H列が全件「○」になるまでPhase 4に進まない。

### ダッシュボードタブ
A:指標名 / B:値 / C:前日比 / D:備考
主な指標: 累計公開記事数 / DR / 被リンク数 / オーガニックKW数 / 推定トラフィック / インデックス済数 / 今月公開数 / AI Overviewインプレッション / AI引用ページ数 / AI参照セッション

### 記事作成ログタブ
A:記事# / B:制作日 / C:KW / D:タイトル / E:URL / F:カテゴリ / G:Volume / H:品質ループ回数 / I:品質スコア(/100) / J:ステータス / K:公開パス（site/内） / L:備考
※パイプラインは必ず「未着手」行の一番上から開始する。

### KPIレポートタブ
A:日付 / B:総公開記事数 / C:本日公開数 / D:インデックス率 / E:PV / F:表示回数 / G:クリック数 / H:CTR / I:平均順位 / J:AI Overview imp / K:AI参照セッション / L:備考

### AIO計測タブ
A:日付 / B:AI Overview imp / C:AIモード imp / D:AI引用ページ数 / E:ChatGPT参照 / F:Perplexity参照 / G:Gemini参照 / H:Copilot・その他参照 / I:引用スポットチェック結果 / J:備考

### 内部リンク管理タブ
A:リンク元記事 / B:リンク先記事 / C:アンカーテキスト / D:設置日 / E:リンク先URL

### リライトログタブ
A:記事# / B:リライト日 / C:リライト理由 / D:変更箇所概要 / E:リライト前順位 / F:リライト後順位（1週間後） / G:前後のAI Overview引用有無 / H:効果

### エラーログタブ
A:日付 / B:Phase / C:エラー内容 / D:対応内容 / E:解決状態
