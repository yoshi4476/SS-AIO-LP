# 管制塔スプレッドシートの使い方

## 文字が途中で切れて読めないとき

列の幅が既定（約100px）のままだと、URL・ご相談内容・エラー内容が
途中で切れる。表を開いても中身が読めないので、判断に使えない。

### 直し方

手元で次の1行を実行する。エディタを開く必要はない。

```bash
python scripts/sheet_format.py
```

整えたあと、実際に切れていないかをその場で検査して結果を出す。
週次の最適化（Weekly Optimize）でも自動で走るため、
行が増えて崩れても翌週には戻る。

書き換えずに状態だけ見たいときは `--check` を付ける。

### 何をしているか

整形そのものは Apps Script 側の **`formatBook`**（`automation/gas/format.gs`）が持つ。
シートを書き換えられるのは管制塔の口だけなので、手元の
`scripts/sheet_format.py` はそれを呼ぶだけにしてある。
同じ処理を2か所に書くと、片方だけ直して食い違うため。

Apps Script のエディタから直したいときは、
**拡張機能 → Apps Script** を開き、関数一覧から `formatBook` を実行しても同じ。

### どう決まるか

タブごとに列幅を決めている（`format.gs` の `COL_WIDTH`）。
あわせて次を揃える。

- 見出し行を固定し、紺色・白抜き・太字にする
- 本文セルは折り返す（**折り返しが無いと右端で切れる**）
- 1行おきに薄い背景を敷き、行を目で追えるようにする
- 日付・率・件数は表示形式を揃える
- 状態・温度の列は、公開済み＝緑／作業中＝黄／エラー＝赤で色を付ける

### 検査が見ているもの

「整えたつもりで実は切れている」を防ぐため、書式を推測せず
実際のセルを読んで確かめる。切れるのは次の2つだけなので、そこを不合格にする。

| 判定 | 内容 |
|:--|:--|
| 不合格 | 本文セルが折り返しでない（CLIP / OVERFLOW は右端で切れる） |
| 不合格 | 見出しが列幅に入らない（見出しは折り返さない運用のため切れる） |
| 助言 | 折り返して縦に長い（切れてはいない。読みにくければ幅を広げる） |

列を広げたいときは `automation/gas/format.gs` の `COL_WIDTH` を直し、
Apps Script へ配信してから `formatBook` を実行する。
