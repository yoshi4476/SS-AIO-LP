# 管制塔スプレッドシートの使い方

## 文字が途中で切れて読めないとき

列の幅が既定（約100px）のままだと、URL・ご相談内容・エラー内容が
途中で切れる。表を開いても中身が読めないので、判断に使えない。

### 直し方

スプレッドシートのメニューから **拡張機能 → Apps Script** を開き、
関数一覧から **`fixColumnWidths`** を選んで実行する。1回で全タブの幅が整う。

新しく作るスプレッドシートは `setup` の時点で幅が入るため、この操作は不要。

### どう決まるか

列の位置ではなく、**見出しの意味**で決めている。列を足したり並べ替えても崩れない。

| 見出しに含まれる語 | 幅 | 折り返し |
|:--|--:|:--|
| 内容・備考・概要・理由・狙い・詳細 | 420px | する |
| URL・ページ・タイトル・キーワード・メール | 240px | する |
| 日時・日付・数・率・順位・スコア・状態・状況 | 110px | しない |
| それ以外 | 150px | しない |

見出し行だけは折り返さない。折り返すと1行目だけ高くなって読みにくい。
