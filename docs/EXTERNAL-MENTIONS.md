# 外部での言及をつくる

AI検索（AI Overview・ChatGPT・Perplexity）は、自社サイトの記述だけで会社を判断しない。
**同じ事実が複数の外部サイトで一致しているか**を見る。逆に言えば、表記がぶれた言及を
増やすほど確信度は下がる。この文書は「どこに」「何を」「どう書くか」を固定するためのもの。

正本のデータは [data/company_profile.json](../data/company_profile.json)。
公開中の3サイトが揃っているかは `python scripts/nap_check.py` で確認する。

---

## 0. 最初に知っておくこと — 同名の別法人がいる

| | 当社 | 別法人 |
| --- | --- | --- |
| 商号 | **セブンセンシズ**株式会社 | 株式会社**セブンセンシズ** |
| 所在地 | 大阪市東成区 | 東京都目黒区 |
| 法人番号 | `3120001227825` | `9120001168304` |

名前だけでは機械が区別できないため、**外部に出す文面には必ず法人番号を入れる**。

3サイトとも対応済み（`Organization` の `identifier` に法人番号、`sameAs` に法人番号ページ、
会社概要ページにも法人番号を掲載）。

### もうひとつの混同要因

`www.7senses.co.jp` は旧サイト（草刈り・造園・害虫害獣駆除）が動いている。
同じ社名で事業内容がまったく違うページが存在する状態なので、
**外部に出すURLは必ず `https://corp.7senses.co.jp/`** にすること。`www` は使わない。

### 実績表記について（要確認）

現在、サイト間で表記がぶれている。**AI集客ラボは「3,200店舗」、コーポレートは「3,200社」**。
数える単位が違うと、同じ事実なのか別の事実なのか機械が判断できない。

`PROJECT.md` と `data/first_party_facts.json` は「店舗」で記録しているため、
本書も**「通算3,200店舗以上」に統一**した。1社が複数店舗を運用している場合、
社数と店舗数は一致しない。**どちらが正しいかを確認し、片方に寄せること。**

## 3. 登録先の優先順

「手間」は1回あたりの作業量、「効きめ」はAI検索・検索エンジンが参照する度合い。
**上から順にやる。** 下に行くほど費用対効果が落ちる。

### 第1階層 — 先にここを埋める（無料・効きめ大）

| 登録先 | 手間 | なぜ効くか |
| --- | --- | --- |
| Googleビジネスプロフィール | 中 | マップとナレッジパネルの源。NAPの基準点になる。**サイトURLをcorpに更新すること** |
| 国税庁 法人番号公表サイト | なし | 登録済み。商号・所在地が正であることの確認だけ |
| Wantedly / Green などの採用媒体 | 中 | 会社概要が構造化された形で公開され、AIに読まれやすい |
| X・Facebookページ | 小 | プロフィール欄にNAPと法人番号を入れる。`sameAs` に追加できる |
| YouTube チャンネル概要 | 小 | 同上。動画がなくても概要欄は索引される |

### 第2階層 — 業種の文脈がつく（無料〜低額）

| 登録先 | 手間 | なぜ効くか |
| --- | --- | --- |
| ITreview / BOXIL / 発注ナビ などのIT比較媒体 | 中 | 「AIコンサルティング会社」としての文脈が付く |
| ミツモア / アイミツ などの発注マッチング | 中 | 同上。問い合わせも発生する |
| 大阪商工会議所・地域の事業者一覧 | 中 | 地域 × 業種の文脈。MEOにも効く |
| 補助金支援事業者の一覧（IT導入支援事業者など） | 小 | 既に登録があれば、掲載名と住所を第1章の表に揃える |

### 第3階層 — 記事として言及される（手間は大きいが最も強い）

| 手段 | 手間 | なぜ効くか |
| --- | --- | --- |
| プレスリリース配信（PR TIMES 等） | 大 | 転載先が増え、複数ドメインで同じ事実が並ぶ。第4章に原稿あり |
| 業界メディアへの寄稿・取材 | 大 | 第三者の文脈で言及される。AI検索が最も重く扱う形 |
| 登壇・セミナー（主催者サイトに掲載される） | 大 | 同上。実績の裏付けにもなる |

### やらないほうがよいこと

- **相互リンク集・被リンク販売**: AI検索の評価には繋がらず、検索エンジンの評価を落とす
- **表記のゆれた登録**: `株式会社セブンセンシズ` と書くと、東京の別法人に寄せる材料になる
- **旧サイト（`www`）のURLで登録**: 事業内容が違うページに誘導してしまう

### 登録したら

そのページのURLを `sameAs` に追記する。管制塔では
[data/company_profile.json](../data/company_profile.json) の `same_as` に足すと、
ai-lab のビルドで全ページに反映される。コーポレートは `src/lib/schema.ts`、
補助金サイトは各HTMLの `Organization` に手で追記する。

**法人番号または正確な住所が載っているページだけ**を入れること。
名前しか載っていないページを入れると、別法人との混同を自分から強めることになる。
