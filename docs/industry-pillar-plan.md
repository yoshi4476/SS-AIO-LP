# 業種別ピラーページ計画（着手条件: クラスター記事が業種あたり10本）

> 目的: /industry/〈業種〉/ に「業種特化の完全ガイド（ピラー）」を置き、クラスター記事と相互リンクで結んで
> 「〈業種名〉 集客」「〈業種名〉 MEO」等のミドルKWを面で取る。
> **今すぐ薄いページを作るとサイト評価を下げるため、記事が揃ってから着手する**（本ドキュメントはその設計図）。

## 対象3業種と狙うピラーKW

## ピラーページの構成テンプレート

1. 冒頭200字断言回答（この業種の集客の結論）
2. 業種特有の検索行動データ（出典付き）
3. 施策の全体地図（MEO/SEO/AIO優先順位はこの業種ではこうなる）
4. クラスター記事への案内（10本を文脈付きで内部リンク）
5. 業種特有の失敗例・規制注意（医療広告GL等）
6. 90日ロードマップ（業種版）
7. FAQ 5問 + 診断・無料相談CTA

## 運用ルール

- クラスター記事はすべて該当ピラーへ内部リンク（ピラー完成前は完全ガイド記事へ）
- ピラー公開時に、既存クラスター記事のリンク先を一括で張り替える（Phase 7の内部リンク管理タブに記録）
- 進捗管理: 記事作成ログのF列（カテゴリ）に業種タグを併記して本数をカウント
