AI集客用語集

AI検索時代の集客でよく使う12の用語を、1語60字以内で定義しました。各用語の詳しい実践方法は関連記事で解説しています。（2026年7月時点）

AIO
AI Overview Optimization

AIOとは、Google検索のAIによる回答（AI Overview）に自社情報が引用されるよう最適化する施策です。

→ AIO対策の5つの手順

LLMO
Large Language Model Optimization

LLMOとは、ChatGPTやPerplexity等のAIチャットの回答で自社が引用・言及されるための最適化施策です。

→ LLMO対策の7つの方法

GEO
Generative Engine Optimization

GEOとは、生成AIエンジン全般への最適化の総称で、AIOとLLMOを含む上位概念として使われます。

AEO
Answer Engine Optimization

AEOとは、強調スニペット等の回答エンジンに選ばれるための最適化で、AIO施策に包含されます。

SEO
Search Engine Optimization

SEOとは、検索結果で上位表示されるための最適化施策です。AI引用の前提条件となる土台です。

→ AI時代のSEOの基本

MEO
Map Engine Optimization

MEOとは、Googleマップの検索結果で上位表示され、店舗が選ばれるための最適化施策です。

→ MEO対策のやり方7ステップ

AI Overview
AIによる概要

AI Overviewとは、Google検索結果の最上部に表示される、AIが生成した回答枠のことです。引用元リンクを含みます。

ゼロクリック検索
Zero-click Search

ゼロクリック検索とは、検索結果画面で答えを得て、どのサイトもクリックせずに終わる検索行動のことです。

E-E-A-T
Experience, Expertise, Authoritativeness, Trust

E-E-A-Tとは、経験・専門性・権威性・信頼性の頭文字で、Googleがコンテンツ品質を評価する基準です。

構造化データ
Structured Data / Schema.org

構造化データとは、ページ内容の意味を検索エンジンやAIに伝えるための機械可読なマークアップです。

llms.txt
LLMs Text File

llms.txtとは、サイト概要と主要ページをAIクローラー向けにまとめた、サイトルートに置くテキストファイルです。

Googleビジネスプロフィール
Google Business Profile

Googleビジネスプロフィールとは、Googleマップと検索に店舗情報を表示する無料ツールで、MEO対策の基盤です。
