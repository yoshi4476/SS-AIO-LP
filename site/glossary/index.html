AI集客用語集

AI検索時代の集客でよく使う30の用語を、1語60字以内で定義しました。各用語の詳しい実践方法は関連記事で解説しています。（2026年7月時点）

AIO
AI Overview Optimization

AIOとは、Google検索のAIによる回答（AI Overview）に自社情報が引用されるよう最適化する施策です。

→ AIO対策の5つの手順

LLMO
Large Language Model Optimization

LLMOとは、ChatGPTやPerplexity等のAIチャットの回答で自社が引用・言及されるための最適化施策です。

→ LLMO対策の7つの方法

GEO
Generative Engine Optimization

GEOとは、生成AIエンジン全般への最適化の総称で、AIOとLLMOを含む上位概念として使われます。

AEO
Answer Engine Optimization

AEOとは、強調スニペット等の回答エンジンに選ばれるための最適化で、AIO施策に包含されます。

SEO
Search Engine Optimization

SEOとは、検索結果で上位表示されるための最適化施策です。AI引用の前提条件となる土台です。

→ AI時代のSEOの基本

MEO
Map Engine Optimization

MEOとは、Googleマップの検索結果で上位表示され、店舗が選ばれるための最適化施策です。

→ MEO対策のやり方7ステップ

AI Overview
AIによる概要

AI Overviewとは、Google検索結果の最上部に表示される、AIが生成した回答枠のことです。引用元リンクを含みます。

ゼロクリック検索
Zero-click Search

ゼロクリック検索とは、検索結果画面で答えを得て、どのサイトもクリックせずに終わる検索行動のことです。

E-E-A-T
Experience, Expertise, Authoritativeness, Trust

E-E-A-Tとは、経験・専門性・権威性・信頼性の頭文字で、Googleがコンテンツ品質を評価する基準です。

構造化データ
Structured Data / Schema.org

構造化データとは、ページ内容の意味を検索エンジンやAIに伝えるための機械可読なマークアップです。

llms.txt
LLMs Text File

llms.txtとは、サイト概要と主要ページをAIクローラー向けにまとめた、サイトルートに置くテキストファイルです。

Googleビジネスプロフィール
Google Business Profile

Googleビジネスプロフィールとは、Googleマップと検索に店舗情報を表示する無料ツールで、MEO対策の基盤です。

→ 口コミを増やす方法

強調スニペット
Featured Snippet

強調スニペットとは、検索結果の上部に回答を抜粋表示する枠のことです。獲得するとAI引用にも近づきます。

ローカルパック
Local Pack

ローカルパックとは、地域系の検索で最上部に出るマップ+上位3店舗の表示枠のことです。MEOの主戦場です。

NAP
Name, Address, Phone

NAPとは、店名・住所・電話番号のことです。全媒体で表記を統一することがMEOと信頼性評価の基本になります。

サイテーション
Citation

サイテーションとは、他サイトやSNSで自社の名前・住所等が言及されることです。リンクがなくても評価に働きます。

被リンク
Backlink

被リンクとは、外部サイトから自社サイトへ張られたリンクのことです。質の高い被リンクは権威性の中心的な評価要素です。

ドメインパワー
Domain Authority

ドメインパワーとは、サイト全体の権威性を表す通称です。被リンク・運用歴・言及の蓄積で高まります。

インデックス
Index

インデックスとは、検索エンジンのデータベースにページが登録されることです。未登録のページは検索に出ません。

クローラー
Crawler

クローラーとは、Web上のページを自動巡回して情報を収集するプログラムです。Googlebotが代表例です。

AIクローラー
AI Crawler

AIクローラーとは、AIサービスが情報収集に使う巡回プログラムです。GPTBotやPerplexityBotなどがあります。

robots.txt
Robots Text File

robots.txtとは、クローラーの巡回可否をサイト側から指示するファイルです。AIクローラーの許可設定にも使います。

検索意図
Search Intent

検索意図とは、検索した人が本当に知りたい・したいことです。記事は検索意図への回答として設計します。

ロングテールキーワード
Long-tail Keyword

ロングテールキーワードとは、検索数は少ないが意図が明確な複合語です。中小企業が最初に狙うべき戦場です。

トピッククラスター
Topic Cluster

トピッククラスターとは、全体ガイド（ピラー）と各論記事を内部リンクで結ぶ構造です。専門性の評価を高めます。

エンティティ
Entity

エンティティとは、検索エンジンやAIが認識する「固有の存在」です。社名の表記統一がAIの正しい認識につながります。

リッチリザルト
Rich Result

リッチリザルトとは、FAQや星評価つきなどの拡張された検索結果表示です。構造化データの設定で表示されます。

指名検索
Branded Search

指名検索とは、社名・サービス名で直接検索されることです。AI引用で認知が増えるほど指名検索も増えます。

CTR
Click Through Rate

CTRとは、表示回数のうちクリックされた割合です。タイトルとメタディスクリプションの改善で高められます。

CVR
Conversion Rate

CVRとは、訪問者のうち問い合わせ等の成果に至った割合です。集客の質とサイトの導線設計を映す指標です。
