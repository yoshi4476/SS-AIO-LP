URL診断（サイトの技術チェック）

URLを入力するだけで、AIが入れるか・検索に出るか・内容を読み取れるかを14項目・100点満点で自動採点。AIクローラーの許可やCDNでの遮断、noindexまで、その場でチェックします。

※ 登録不要。対象はご自身が管理するサイト、または公開されているページに限ります。

How to use

使い方は3ステップ

  1. URLを入れる確かめたいページのURLを入れて「チェック」を押します。登録は要りません。
  2. 14項目を自動で検査ページを実際に取得し、AIが入れるか・検索に出るか・内容を読み取れるかを機械的に調べます。
  3. 不合格を上から直す項目ごとの合否と点数が出ます。不合格の項目を上から順に直せば対応が進みます。
Result

結果でわかること

AIが入れるか（26点）
AIのクローラーを robots.txt で拒否していないか、CDN・WAF の入口で弾いていないか、常時SSLか。
検索に出るか（40点）
検索に出さない設定（noindex）になっていないか、タイトル・説明文・正規URL・スマホ表示。
内容を読み取れるか（32点）
見出しH1、会社情報（電話番号・所在地）、構造化データ、画像の代替テキスト、OGP、llms.txt。
直す順番
配点の大きい項目から並ぶので、どこから手を付けるかがその場で決まります。

About

このチェックでわかること

サイトの技術チェックは、入力されたページを実際に取得し、AI検索とSEOの技術対応14項目を機械的に検査して100点満点で採点するツールです。重く見ているのは、AIのクローラーが入れるか（robots.txtとCDNでの遮断）と、検索に出さない設定（noindex）になっていないかです。Googleが「効く」と明記しているのは、クロールできることと、その会社にしか書けない内容だからです。構造化データとllms.txtは、GoogleがAIに引用されるための必須条件ではないと明言しているため、配点を低くしています。

85点以下だった場合は、改善余地がそのまま集客の伸びしろです。結果には項目ごとの合否が表示されるため、不合格項目を上から順に直すだけで対応が進みます。技術的な修正が難しい場合や、コンテンツ面（記事の構造・一次情報）まで含めた本格的な分析が必要な場合は、無料の現状分析をご利用ください。

※ 本チェックは公開ページの機械検査であり、検索順位やAI引用の実績そのものを測定するものではありません。コンテンツ対応もあわせて確認したい方はAI検索対応度チェック（30秒）を、店舗のマップ対策はMEO対応度チェック（30秒）をどうぞ。チェック項目の意味から知りたい方はAIO対応のチェックのやり方｜無料チェック8項目とツールの使い分けもあわせてご覧ください。
