**会計事務所は、顧問先の記帳代行を外部に分担できます。**記帳の入力は、税理士の独占業務に入らないためです。ただし、顧問先の秘密を守る責任と、作業を監督する責任は事務所に残ります。**外に出す前に決めるのは、同意・契約・データ・記録・戻し先の5点です。**

## 会計事務所は記帳代行を外部に分担してよいのか？

会計事務所が顧問先の仕訳入力を外部に分担することは、税理士法上も認められる働き方です。

国税庁の<a href="https://www.nta.go.jp/taxes/zeirishi/zeirishiseido/qa/02.htm" target="_blank" rel="noopener">「税理士業務とは」</a>は、*税理士業務*を税務代理・税務書類の作成・税務相談の3つに分けています。仕訳の入力と帳簿の作成は、この3つに入りません。

<div class="definition-box"><span class="term">記帳代行の外部分担とは</span>、会計事務所が顧問先から預かった証憑の入力を外部の会社に任せ、税務の判断と申告は事務所に残す働き方です。==申告書を作る人は変わりません。==</div>

外に出してよいのは「入力」までです。**税額が変わる判断を外注先にさせると、無資格の税務相談に近づきます。**独占業務の境目は、[記帳代行は税理士法違反？3つの独占業務とNG事例](/blog/kichodaiko-zeirishihou-ihan/)で詳しく整理しています。

当社にも、手がいっぱいの税理士事務所から、業務を分担できないかという問い合わせがありました。当社はその事務所と、業務を分担する提携を結びました。同じような問い合わせは増えています。当社は、入力と試算表を外注先が受け持ち、判断を事務所に返す分け方が安全だと考えています。

## 外に出す業務と、事務所に残す業務の線引き

会計事務所が外注先に任せるのは毎月繰り返す入力で、税額と顧問先との約束に関わる仕事は事務所に残します。

線を引く基準は「その判断で税額が変わるか」です。下の表は、記帳まわりの業務ごとに担い手を分けたものです。

| 業務 | 外注先に任せる | 事務所に残す |
|:--|:--|:--|
| 証憑の整理・スキャン | ○ | |
| 会計ソフトへの仕訳入力 | ○ | |
| 試算表・総勘定元帳の作成 | ○ | |
| 勘定科目の迷う仕訳の判断 | | ○ |
| 決算書・申告書の作成 | | ○ |
| 顧問先への説明と税務相談 | | ○ |

顧問先との窓口も事務所に残してください。外注先が顧問先と直接やり取りを始めると、**顧問先は誰が責任者か分からなくなります。**当社は、顧問先への連絡は事務所を通す形にすべきだと判断しています。

## 会計事務所が記帳を外注する前に確かめる5点

記帳を外に出す前に、会計事務所は同意・契約・データ・記録・戻し先の5点を書面で決めてください。

<figure><img src="/images/kichodaiko-kaikei-jimusho/kakunin.png" alt="外に出す前に確かめる5点: 顧問先の書面の同意、守秘の契約、データの置き場と権限、指示と確認の記録、迷う仕訳の戻し先" loading="lazy"><figcaption>外に出す前に確かめる5点</figcaption></figure>

5点の根拠は、3つの条文です。税理士法38条は、正当な理由なく業務で知った秘密を漏らすことを禁じています（<a href="https://www.nta.go.jp/taxes/zeirishi/zeirishiseido/qa/06.htm" target="_blank" rel="noopener">国税庁「税理士法違反行為」</a>）。

税理士法41条の2は、使用人その他の従業者を使う税理士に監督を求めています（<a href="https://www.kinzei.or.jp/search/regulation/chapter_4_16.html" target="_blank" rel="noopener">近畿税理士会「Web税理士法」</a>）。個人情報保護法25条は、個人データの扱いを委託するときに委託先の監督を求めています（<a href="https://laws.e-gov.go.jp/law/415AC0000000057" target="_blank" rel="noopener">e-Gov法令検索</a>）。

1. **顧問先の書面の同意**は、証憑を外部に渡すことへの同意です。顧問契約の更新時に1枚足すと、まとめて取れます
2. **守秘の契約**は、外注先と結ぶ秘密保持の契約です。契約が終わった後の扱いも書きます
3. **データの置き場と権限**は、証憑と会計データをどこに置き、誰が見られるかの取り決めです
4. **指示と確認の記録**は、事務所が何を指示し、どの仕訳を確かめたかの記録です
5. **迷う仕訳の戻し先**は、外注先が判断に迷った仕訳を、事務所の誰に返すかの決まりです

4点目の記録は、離れた場所での作業にも関わります。近畿税理士会の解説では、令和4年の改正で、遠隔での管理監督を想定した通達（基通41の2-1）が設けられました。外注先が事務所の外で入力するなら、指示と確認の記録が監督の跡になります。

5点目を決めずに始めるのが、いちばん多い抜けです。外注先の担当者が自分で科目を決めると、**判断の記録が事務所に残りません。**

## 記帳の分担を毎月どう回すか

会計事務所と外注先の分担は、証憑の回収から試算表の送付までを毎月同じ順番で回すと崩れません。

<figure><img src="/images/kichodaiko-kaikei-jimusho/mawashikata.png" alt="記帳の分担を毎月回す流れ: 証憑を集める、外注先が入力、事務所が検収、迷う仕訳を判断、試算表を顧問先へ" loading="lazy"><figcaption>記帳の分担を毎月回す流れ</figcaption></figure>

流れは5段です。事務所が顧問先から証憑を集め、外注先が入力します。事務所が戻った仕訳を検収し、迷う仕訳を判断します。最後に、試算表を事務所から顧問先へ送ります。

順番を固定すると、月次の締めが前に倒れます。当社が経理代行を担当した9社では、月次の締めが平均で**翌月20日から翌月8日に、約12日早まりました**（2023年4月〜2026年9月。最も早い会社は翌月5日）。この9社は会計事務所の顧問先に限った数字ではありません。

外注先に業務を渡すときの資料のそろえ方は、[経理外注の引き継ぎ失敗例](/blog/keiri-gaichuu-hikitsugi/)にまとめています。

## 外注先から戻った仕訳で事務所が見る4項目

会計事務所の検収では、外注費と給与の区分・備品の資産計上・前払費用・源泉徴収の4項目を先に見てください。

<figure><img src="/images/kichodaiko-kaikei-jimusho/ayamari.png" alt="経理代行で直した仕訳の誤り: 外注費と給与の区分40件、備品の消耗品処理25件、前払費用の計上漏れ15件、源泉徴収の漏れ10件" loading="lazy"><figcaption>経理代行で直した仕訳の誤り</figcaption></figure>

4項目は、当社が実際に直した誤りの多い順です。2023年4月から2026年9月までに経理代行で担当した7社で、直した仕訳の誤りは**7社の合計で年間約90件**でした。

| 誤りの種類 | 7社で直した件数（年間） | 検収で見る点 |
|:--|:--|:--|
| 外注費と給与の区分 | 約40件 | 同じ人へ毎月払う外注費 |
| 備品の消耗品処理 | 約25件 | 資産に計上すべき備品が消耗品になっていないか |
| 前払費用の計上漏れ | 約15件 | 年払いの保険料・家賃 |
| 源泉徴収の漏れ | 約10件 | 士業・個人への報酬 |

4項目は、どれも税額に響く判断です。**入力の速さより、判断の要る仕訳だけを事務所に戻す仕組みが効きます。**

業種ごとの癖もあります。建設業の会社3社の経理代行で、実際に直した仕訳の誤りは接待交際費の扱いでした（2026年10月時点）。建設業の顧問先を外に出すなら、交際費の科目は事務所で確かめる項目に足してください。

## 記帳の外部分担で起きやすい失敗と避け方

記帳の外部分担の失敗は、外に出す顧問先の選び方と、判断の線引きのあいまいさから起きます。

当社が2023年4月から2026年9月までに経理代行の依頼をお断りした、または合わなかった例は**7件**です。理由は次のとおりです。

<div class="caution-box"><span class="box-title">NG: 現金中心の顧問先をそのまま外に出す</span><br><strong>起きたこと</strong>は、証憑がそろわず入力が進まなかったことです（当社で3件）。<br><strong>原因</strong>は、現金取引が中心で領収書が残っていなかったことです。<br><strong>避け方</strong>は、<span class="txt-red">証憑がそろう顧問先だけを外に出す</span>ことです。</div>

決算の直前に記帳をまとめて外に出すのも失敗の形です。当社で2件あり、どちらも期限に間に合いませんでした。**外に出すのは、毎月証憑が届く顧問先に限ってください。**

残りの2件は、税務の判断まで求められた例でした。外注先は判断を引き受けられません。迷う仕訳の戻し先を、契約の時点で決めてください。

## 記帳の外部分担が向く会計事務所・向かない会計事務所

職員の手が記帳で埋まり、相談や決算に時間を回せない会計事務所には外部分担が向き、記帳の件数が少ない事務所は見送ってください。

| 事務所の状況 | 判断 | 理由 |
|:--|:--|:--|
| 職員が記帳に追われ、決算の準備が遅れる | 外に出す | 入力を外すと、判断の仕事に時間を回せる |
| 毎月証憑が届く顧問先が多い | 外に出す | 毎月同じ順番で回せる |
| 現金中心・決算前にまとめる顧問先が多い | 見送る | 断った7件のうち5件（現金中心3件・決算前2件）がこの2つ |
| 記帳を職員の育成の場にしている | 一部だけ出す | 育成用の顧問先は事務所に残す |

判断の目安には、記帳にかけている時間を使います。試算：顧問先10社の記帳に、1社あたり月5時間かけているなら、月50時間です。仮にその50時間を相談と決算に回せるなら、外に出す意味があります。

例えば、1社あたり月5時間のうち検収に月1時間かかるなら、浮くのは月4時間です。外注先の見積もりは、この浮く時間と比べてください。当社の費用は顧問先の数と仕訳の件数で変わるため、見積もりで確かめられます。

時間が浮いても、検収に時間が取られれば効きません。当社の判断では、4項目の検収を職員が回せる体制があるときだけ外に出すべきです。

条件が重なる顧問先もあります。「毎月証憑が届く」と「現金中心」の2つ以上に当てはまるなら、**見送りを先にしてください。**当社が断った7件のうち3件が現金中心の会社で、入力が進まない理由はそこにありました。現金の領収書が月ごとにそろうようになってから、外に出す顧問先へ移してください。

続くかどうかも、外注先を選ぶ材料になります。2023年4月から2026年9月までに当社が経理代行・記帳代行を担当した48社のうち、31社は継続中です。料金表の読み方は、[記帳代行料金表は税理士事務所でどう読む？](/blog/kichodaiko-ryokinhyo-zeirishi/)を見てください。

## 外注先を選ぶとき会計事務所が聞く5つの質問

会計事務所が記帳の外注先を選ぶときは、料金より先に再委託・データの返却・会計ソフト・担当の交代・戻し方の5つを聞いてください。

5つとも、顧問先の秘密と事務所の監督に関わる質問です。答えを書面でもらえるかも、比べる材料になります。

1. 入力をさらに別の会社や個人に回すかを聞きます。再委託があると、守秘の契約が届かない先に証憑が渡ります
2. 契約が終わったとき、証憑と会計データをどう返し、どう消すかを聞きます。消した記録を出せるかも確かめます
3. 事務所が使っている会計ソフトで入力できるかを聞きます。ソフトが違うと、検収のたびに変換の手間が出ます
4. 担当者が替わるとき、どう引き継ぐかを聞きます。科目の癖は顧問先ごとに違うため、引き継ぎの資料が要ります
5. 迷った仕訳を、いつまでに、どの形で返すかを聞きます。返す期限が無いと、月次の締めが外注先の都合で遅れます

当社は、再委託が無く、迷った仕訳を事務所に返す外注先を選ぶべきだと考えています。費用は、顧問先の数と仕訳の件数で変わります。

答えがあいまいな外注先は見送ってください。**特に1と2に答えられない先は、守秘の契約を結んでも中身が守られません。**

外注先を探す下調べとして、AIが何を出典にするかも参考になります。当社は2026年10月に、2つのAI（ChatGPT・Claude）へ経理代行・記帳代行に関する質問を50問聞き、答えの出典668件を種類ごとに数えました（<a href="https://ai.7senses.co.jp/research/keiri-ai-sources/" target="_blank" rel="noopener">業種調査</a>）。経理代行会社を探す質問では、出典の28.8%が比較・紹介サイト、56.1%が経理代行会社の公式サイトでした。

比べるときは、紹介サイトだけでなく外注先の公式サイトの説明も読んでください。公式サイトに再委託やデータの扱いが書かれているかを見れば、5つの質問の下調べになります。

当社調べでは2026年11月に、1つのAI（Gemini）へ本記事の論点5問を質問し、答え5件を得ました。5件の答えのうち、触れていたのは期間（◯か月・◯日など）は1件、進め方の手順は1件、費用の金額（◯円）は2件でした。AIの答えだけでは手順や期間が足りないため、外注先への質問は書面で確かめてください。

## 今日やること：外に出す顧問先を3つの印で分ける

会計事務所が記帳の分担を始める最初の一歩は、顧問先の一覧に「出す・出さない・迷う」の印を付けることです。

まず、顧問先の一覧を開いてください。印は次の表のとおりに付けます。

| 印 | 付ける顧問先 | 扱い |
|:--|:--|:--|
| 出す | 毎月証憑が届く | 5点の書面を作って外注先へ |
| 出さない | 現金中心、決算前にまとめて持ち込む | 事務所で記帳を続ける |
| 迷う | 証憑は届くが科目の判断が多い | 事務所に残し、毎月見直す |

「出す」が付いた顧問先から、5点の書面を1社分だけ作ります。1社で1か月回し、検収の4項目で直しが何件出たかを数えてください。

続けるかの目安は、直しが出た仕訳の割合です。仮に、検収した仕訳のうち直しが1割を超えるなら、その月は拡大せず、戻し方を見直してください。当社の判断では、直しが多いと検収の手間が入力の手間を上回るためです。

「迷う」の顧問先は、仮に3か月続けて迷う仕訳が月に数件で収まるなら、「出す」へ移してかまいません。迷う仕訳が毎月増えるなら、「出さない」に移してください。

顧問先の側から見た任せ方は、[税理士に記帳代行を丸投げすると月次が遅れる？](/blog/zeirishi-kichodaiko-marunage/)で整理しています。資格の無い会社に頼む線引きは、[記帳代行は資格なしの会社でも頼める？](/blog/kichodaiko-shikaku-nashi/)が参考になります。

## まとめ: 外に出すのは入力、残すのは判断と責任

<span class="big">会計事務所は記帳の入力を外部に分担できます。守秘と監督の責任、税額が変わる判断は事務所に残ります。</span>

外に出す前に、同意・契約・データ・記録・戻し先の5点を書面で決めてください。戻った仕訳は、外注費と給与・備品・前払費用・源泉徴収の4項目から検収します。現金中心の顧問先と、決算前にまとめる顧問先は外に出さないでください。記帳代行の基本は[記帳代行とは？](/blog/kichodaiko-toha/)で解説しています。
